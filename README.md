# murderwalk.com → moordwandeling.nl

Murder Walk is samengevoegd met Moordwandeling. Deze repo stuurt alleen nog door: elke pagina op murderwalk.com gaat naar hetzelfde pad op moordwandeling.nl (Engelse pagina's staan daar in de root). De startpagina krijgt `?en`, zodat bezoekers in het Engels uitkomen. Zaak- en groepslinks (`#z=…`, `#g=…`) blijven werken.

index.html en 404.html zijn hetzelfde bestand; CNAME blijft staan zodat het domein bij GitHub Pages blijft.
